# Syriana Grill

Website for Syriana Grill, a family-owned Syrian kitchen at 6857 St Augustine Rd, Unit 9, Jacksonville, FL 32217.

The whole site lives in `index.html`. Photos are embedded in the file, so nothing else needs to be uploaded.

## Put it on GitHub

1. Create a new repository on GitHub (for example `syriana-grill`).
2. Click **Add file > Upload files**, drag in `index.html` and `README.md`, then click **Commit changes**.

## Make it a live website (GitHub Pages)

1. In the repository, go to **Settings > Pages**.
2. Under **Build and deployment**, set Source to **Deploy from a branch**, pick `main` and `/ (root)`, then click **Save**.
3. After a minute or two the site will be live at `https://YOUR-USERNAME.github.io/syriana-grill/`.

To use a custom domain (like `syrianagrill.com`), enter it in the **Custom domain** box on that same Pages screen and follow GitHub's DNS instructions.
